# 言點教育．燃亮你心

這是一個為香港中學生設計的繁體中文互動學習網站，整理指定文言文的核心主旨，以及白話文閱讀理解常見的寫作手法。網站採用純 HTML5、CSS 與原生 JavaScript，無需建置步驟即可於靜態主機上運行。

## 功能

網站設有可搜尋及展開的學習卡、寫作手法配對挑戰、五題快問快答，以及儲存在瀏覽器本機的學習進度與徽章系統。卡片內容根據本專案提供的指定文言文及寫作手法筆記濃縮，互動題目均回扣其中的定義、主旨或答題策略。

## 本機預覽

直接以瀏覽器開啟 `index.html`，或使用任何靜態檔案伺服器提供專案根目錄。網站入口在 `index.html`，樣式在 `src/index.css`，互動邏輯與學習資料在 `src/main.js`。

## 內容範圍

文言文學習區包括《論語》論仁、論孝、論君子三個專題，以及《孟子．魚我所欲也》、《莊子．逍遙遊》、《荀子．勸學》、《廉頗藺相如列傳》、《出師表》、《師說》、《始得西山宴遊記》、《六國論》、《山居秋暝》、《月下獨酌》、《念奴嬌．赤壁懷古》和《聲聲慢．秋情》。白話文區收錄高頻修辭、表現及結構手法的易讀摘要。
